🧪 RFC 6238 공식 테스트 벡터 자가진단

RFC 6238 명세의 공식 표준 벡터 (Secret: GEZDGNBVGY3TQOJQGEZDGNBVGY3TQOJQ)를 브라우저의 crypto.subtle로 즉시 연산하여 일치 여부를 검증합니다.

사이버보안 체크포인트: XSS 탈취 방지를 위해 비밀 키를 스토리지(localStorage / sessionStorage)에 저장하지 않고 메모리에서만 연산합니다. 브라우저 외부 API 호출이 전혀 없는 100% Zero-Transmission 구조입니다.
